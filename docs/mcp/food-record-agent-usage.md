# AIO-LIFE 美食记录 Agent 使用说明

> 适用场景：Trae 智能体配置中的“何时调用”，以及用户实际对话时可复制的使用模板。
>
> 关联提示词：`food-record-agent-prompt.md`

## Trae 何时调用

将下面内容复制到 Trae 智能体配置的“何时调用”输入框：

```text
用户围绕 AIO-LIFE 美食模块进行做饭规划、菜品建议、食材清单、烹饪步骤、口味调整、复盘总结、历史做饭记录查询时调用。

仅当用户明确要求写入美食记录，例如“美食记录”“写入美食记录”“帮我记录到美食记录”“记录一下这顿饭”时，才允许调用 MCP 工具 food_record_save。

当用户询问历史美食记录、之前做过什么、某类菜做过哪些、哪些菜值得复做或需要改进时，调用 MCP 工具 food_record_query。

如果用户只是聊天、咨询菜谱、整理购物清单，或明确说“先别记录”“不要入库”，不要调用 food_record_save。
```

## 用户使用模板

### 直接生成并写入 5 份家常菜

```text
请帮我生成 5 份适合日常晚餐的家常菜，并写入美食记录。

要求每份作为独立记录写入，状态为草稿 draft，日期为今天，餐次为晚餐。请自动补全食材、步骤、标签、难度、预计耗时、口味描述、注意事项、简短总结和下次改进建议。

菜品要求：荤素搭配、做法家常、不要太复杂、适合普通家庭厨房完成。

请现在写入美食记录。
```

### 指定 5 道菜并写入

```text
请帮我生成 5 份家常菜，并写入美食记录。

要求：
1. 每份都作为一条独立的 AIO-LIFE 美食记录写入。
2. 状态都用草稿 draft。
3. 日期用今天。
4. 餐次都按晚餐处理。
5. 每份记录都包含菜名、分类、食材、做法步骤、标签、难度、备菜时间、烹饪时间、口味描述、注意事项、简短总结和下次改进建议。
6. 菜品要适合日常家庭做饭，难度以简单或中等为主。

可以参考这 5 道：
- 番茄炒蛋
- 青椒肉丝
- 土豆炖牛腩
- 蒜蓉西兰花
- 紫菜蛋花汤

请现在写入美食记录。
```

### 先预览再写入

```text
请先生成 5 份适合日常晚餐的家常菜草稿给我预览，暂时不要入库。

每份草稿包含菜名、食材、做法步骤、预计耗时、口味特点和注意事项。

等我回复“美食记录”后，再把这 5 份分别写入美食记录。
```

### 查询历史美食记录

```text
帮我查一下最近做过哪些家常菜，优先列出值得复做的记录。
```

```text
帮我查一下之前做过哪些晚餐，有没有需要改进的菜。
```

```text
帮我查一下我以前做过的番茄相关菜品。
```
