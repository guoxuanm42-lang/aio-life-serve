# MCP 工具管理、参考中心与模拟调用更新（2026-06-04）

## 1. 背景与目标

本次更新在现有 MCP 工具注册与调用基础设施上，新增一套面向运营、开发和调试人员的工具管理能力。

此前 MCP 工具主要通过协议端点对 Agent 暴露，缺少统一的可视化入口来确认运行时注册状态、查看参数 Schema、维护展示配置、执行模拟调用和追踪调用结果。本次更新将这些能力集中到“研发管理 / MCP 工具列表”页面，同时让 MCP 协议调用和前端模拟调用复用同一条受控调用链。

主要目标：

- 将运行时 MCP 工具定义与数据库运营配置合并展示。
- 支持工具启停、分组、展示名称、描述覆盖、读写风险和排序配置。
- 提供完整参数参考、JSON 示例、Schema 和调用说明。
- 提供真实模拟调用入口，并展示结构化结果与原始响应。
- 对 MCP 协议调用和 REST 模拟调用统一执行启停校验、限流和审计记录。

## 2. 后端更新

### 2.1 MCP 工具管理 REST API

新增控制器：

- `src/main/java/top/aiolife/mcp/api/McpToolController.java`

新增接口：

| 方法 | 路径 | 用途 | 权限 |
|---|---|---|---|
| `GET` | `/mcp/tools` | 查询运行时工具与运营配置合并后的工具列表 | 登录用户 |
| `POST` | `/mcp/tools/{name}/call` | 从管理页面模拟调用指定 MCP 工具 | 登录用户 |
| `PUT` | `/mcp/tools/{name}/config` | 创建或更新工具运营配置 | `admin` |
| `PUT` | `/mcp/tools/{name}/status` | 启用或停用工具 | `admin` |
| `GET` | `/mcp/tools/{name}/logs` | 查询指定工具最近调用日志 | `admin` |

工具列表返回内容包括：

- 工具名称、展示名称、描述和描述来源。
- 输入参数 `inputSchema`、一级参数数量和是否需要登录。
- 分组、排序、读写操作、启用状态和配置状态。
- 当前运行时是否已注册。

### 2.2 工具运营配置

新增配置实体、Mapper、Service 和请求对象：

- `McpToolConfigEntity`
- `IMcpToolConfigMapper`
- `IMcpToolConfigService`
- `McpToolConfigServiceImpl`
- `McpToolConfigSaveReq`
- `McpToolStatusReq`
- `McpToolVO`

运营配置支持维护：

- `displayName`：面向用户的展示名称。
- `groupName`：工具分组。
- `descriptionOverride`：覆盖运行时描述。
- `enabled`：工具启停状态。
- `writeOperation`：是否属于写操作。
- `sortOrder`：列表排序。
- `remark`：运营备注。

工具列表会合并运行时注册定义和数据库配置：

- 运行时已注册但未配置的工具仍可显示，并使用工具名和运行时描述。
- 数据库已配置但运行时未注册的工具仍可显示，并标记为未注册。
- 未创建配置时，工具默认视为启用。
- 未配置分组时，会按工具名前缀推断“时间、闪念、美食、任务、运动、其他”等分组。

### 2.3 统一调用服务

新增：

- `IMcpToolCallService`
- `McpToolCallServiceImpl`

`McpToolHandlers` 不再直接调用 `McpToolInvoker`，而是委托统一调用服务。前端模拟调用和 MCP 协议调用因此复用相同的执行路径：

1. 校验工具是否存在。
2. 校验工具是否启用。
3. 按“用户 + 工具”进行 Redis 限流，默认每 60 秒最多 30 次。
4. 委托现有 `McpToolInvoker` 执行业务调用。
5. 记录成功、失败、耗时和参数摘要。

停用工具会从 MCP 协议 `tools/list` 结果中隐藏，同时无法通过模拟调用或协议调用执行。

### 2.4 调用审计日志

新增：

- `McpToolCallLogEntity`
- `IMcpToolCallLogMapper`
- `IMcpToolCallLogService`
- `McpToolCallLogServiceImpl`

审计日志记录：

- 工具名称。
- 调用用户。
- 参数摘要。
- 成功或失败状态。
- 错误信息。
- 调用耗时。
- 创建时间。

参数摘要写入数据库前会递归脱敏。字段名包含 `password`、`token`、`key`、`secret`、`authorization` 等敏感关键词时，值会替换为 `***`。日志查询默认返回最近 50 条，最大限制为 200 条。

## 3. 前端更新

### 3.1 路由与 API

新增前端 API 文件：

- `apps/web-antd/src/api/core/mcp.ts`

新增页面路由：

- 路径：`/coding/mcp-tools`
- 页面：`apps/web-antd/src/views/coding/mcp-tools/index.vue`
- 菜单标题：`MCP 工具列表`

前端封装了工具列表、模拟调用、配置保存、状态更新和调用日志查询接口。

### 3.2 MCP 工具列表

工具卡片用于快速识别工具和进入下一步操作，展示内容包括：

- 展示名称或工具技术名称。
- 配置展示名称时，以灰色副标题保留技术名称。
- 分组、读写操作、登录要求和注册状态。
- 单行工具描述，悬停可查看完整内容。
- 弱化显示的参数数量。
- 紧凑的“配置缺失”状态。

操作层级：

- `模拟调用` 为唯一主按钮。
- `查看参考` 为次级操作。
- 管理员可通过更多菜单进入创建/编辑配置和调用日志。
- 管理员可使用启用开关控制工具状态。
- 管理员点击“配置缺失”可直接打开创建配置抽屉。

### 3.3 工具参考中心

新增“查看参考”宽抽屉，负责完整说明工具，而不是在列表卡片中展开大量参数。

参考抽屉包含：

- 工具基础信息：名称、展示名、描述、分组、读写、登录要求、参数数量、注册状态和排序。
- `参数说明` Tab。
- `JSON 示例` Tab。
- `Schema` Tab。
- `调用说明` Tab。

参数说明支持：

- 展示参数名、类型、必填、默认值和说明。
- 搜索参数。
- 只看必填参数。
- 只看复杂参数。
- 展开或收起复杂对象、数组的一层子字段。
- 参数超过 15 个时显示字段分组目录。

JSON 示例支持：

- 对当前已知 MCP 工具提供业务示例。
- 保存工具支持创建示例和更新示例切换。
- 未匹配工具回退到基于 Schema 默认值生成的示例。
- 支持复制示例。
- 支持将示例一键填入模拟调用。

Schema 视图展示原始 `inputSchema` 并支持复制；调用说明区分读操作和写操作风险，展示常见参数组合和注意事项。

### 3.4 模拟调用工作台

模拟调用抽屉调整为更宽的响应式布局：

- 桌面端宽度为 `min(1180px, 92vw)`。
- 小屏宽度为 `100vw`。
- 参数编辑区与调用结果区独立展示。
- 执行按钮固定在抽屉底部操作区。

参数编辑区拆分为：

- `表单参数`：基础类型快速填写。
- `JSON 参数`：完整 arguments JSON 编辑。
- `Schema`：查看原始输入 Schema。

调用结果区保留：

- 成功或失败提示。
- 结构化结果。
- 原始响应 JSON。

写操作工具执行前仍会进行确认，提醒模拟调用会真实写入或更新业务数据。

## 6. 注意事项

- 本次变更依据前后端 Git 工作区中的新增和修改代码整理，相关代码当前尚未提交。
- 工具配置属于全局运营配置，不按用户隔离。
- 前端模拟调用会真实执行工具；写操作可能创建或更新业务数据。
- 工具未创建配置时默认启用，因此上线后应及时确认写操作标记、展示名称、分组和启停状态。
- 中文展示名称需要通过现有“创建/编辑配置”操作录入，前端未硬编码默认中文名称。
- Redis 限流检查失败时采用放行策略，并记录警告日志。
