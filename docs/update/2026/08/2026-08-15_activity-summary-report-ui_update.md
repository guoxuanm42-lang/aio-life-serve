# 活动总结结构化报告与界面升级

## 更新时间

2026-08-15

## 变更内容

- 活动总结生成任务保存 `AiActivitySummaryContext` JSON 快照，幂等重试和历史查看均使用生成时数据。
- 聊天历史响应为活动总结助手消息附加 `activitySummary`，普通消息和旧报告保持兼容。
- 消息中心新增独立报告组件，包含周期封面、核心指标、分布图、活动明细和 AI 复盘正文。
- 报告支持复制和按原周期重新生成；非 HTTPS 环境自动使用兼容复制方案。
- 周期菜单改为实际日期范围、选中态和统一蓝紫视觉。

## 数据库升级

执行：

```sql
source sql/2026-08-15_activity_summary_report.sql;
```

该脚本为 `ai_activity_summary_generation` 增加 `context_json` 快照字段和助手消息查询索引。历史任务没有快照时仍按原 Markdown 消息展示。
