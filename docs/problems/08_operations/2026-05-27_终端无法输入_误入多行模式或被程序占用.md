# 2026-05-27_终端无法输入_误入多行模式或被程序占用

## 1. 现象

- 终端无法输入命令，或输入无反应。
- PowerShell 出现 `>>` 提示符（多行模式），命令无法正常执行。

---

## 2. 根因

- 终端当前有程序正在占用输入（例如某条命令未退出）。
- PowerShell 在语法未闭合时会进入多行输入模式，提示符变为 `>>`（例如引号未闭合、括号未闭合）。

---

## 3. 解决方法

- 若在多行模式（`>>`）或程序卡住，先按 `Ctrl + C` 终止并返回 `PS ...>` 提示符。
- 如果进入分页器（如 `git log` 的 pager），按 `q` 退出。
- 若焦点不在终端输入区，用鼠标点一下终端窗口再输入。
