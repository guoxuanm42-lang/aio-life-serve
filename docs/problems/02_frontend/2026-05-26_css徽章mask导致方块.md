# CSS 徽章使用 mask 渲染彩色 PNG 导致显示为“纯色方块”

## 1. 问题现象
卡片右上角徽章图标显示异常：
- 图标看起来像“一个被主题色填充的方块”
- 看不到原本的图标细节

## 2. 发生场景
将徽章图标从 `<img>` 改为 CSS 渲染时，尝试使用 `mask-image` 给图标上色。

## 3. 原因分析
`mask-image` 的设计目标是“用透明度当蒙版”，它更适合 **单色剪影** 图标（SVG/单色 PNG）。

当用于彩色插画 PNG 时：
- 大面积区域不透明 → 蒙版形状接近“整块”
- 结果就是 `background-color` 被整块填充，看起来像纯色方块

## 4. 解决方案
可选方案：
- 方案 A：不要用 mask，直接用 `background-image` 显示原图（保留原色）
- 方案 B：更换为单色剪影图标（SVG 或单色 PNG）再用 mask 上色
- 方案 C：改为纯 CSS 简易图标（线条/几何图形），避免资源适配与蒙版问题

## 5. 验证方法
- 徽章在不同主题色下均能正常显示图标轮廓，不再出现纯色方块

## 6. 注意事项
- 要“跟随主题色变色”的图标，优先选 SVG（可控、无透明边距问题）。
