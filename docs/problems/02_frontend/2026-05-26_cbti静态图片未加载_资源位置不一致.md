# 2026-05-26_cbti静态图片未加载_资源位置不一致

## 1. 现象

- CBTI 页面图片区域显示为空/占位（例如 996 角色卡片处没有图）。
- Network 中可见图片请求为 404（例如 `/cbti-characters/996.png`）。

---

## 2. 根因

- 前端改为从 `public` 静态目录读取图片：`/cbti-characters/{code}.png`
- 但项目内 CBTI 角色图片实际存在于后端资源目录：
  - `aio-life-serve-main/aio-life-serve-main/src/main/resources/cbti/characters/`
- 前端 `apps/web-antd/public/cbti-characters/` 目录未放置对应图片文件，导致请求 404。

---

## 3. 解决方案

### 3.1 迁移图片到前端 public

将后端资源图片复制到前端：

- 目标目录：`aio-life-front-main/aio-life-front-main/apps/web-antd/public/cbti-characters/`
- 文件名规则：与人格 `code` 一致，当前使用 `.png`

PowerShell（仓库根目录）：

```powershell
Copy-Item -Force -Recurse `
  .\aio-life-serve-main\aio-life-serve-main\src\main\resources\cbti\characters\*.png `
  .\aio-life-front-main\aio-life-front-main\apps\web-antd\public\cbti-characters\
```

### 3.2 验证

- 浏览器直接访问：`http://localhost:5666/cbti-characters/996.png`
- CBTI 页面（`/profile?tab=cbti`）角色图片正常显示。
