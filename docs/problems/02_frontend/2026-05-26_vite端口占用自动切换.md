# Vite dev server 端口占用导致自动切换

## 1. 问题现象
启动前端后终端提示：
- `Port 5666 is in use, trying another one...`
- 最终实际运行在其他端口（例如 `http://localhost:5667/`、`http://localhost:5668/`）

## 2. 发生场景
本机已有旧的前端 dev server 或其他进程占用了默认端口（5666），Vite 会自动寻找可用端口。

## 3. 原因分析
端口冲突导致 Vite 自动换端口，而浏览器仍在访问旧端口，从而产生误判：
- “我改了样式但页面没变”
- “刷新后还是旧页面”

## 4. 解决方案
- 以终端输出的 `Local:` 为准访问页面
- 或停止占用端口的旧进程，确保 dev server 固定在期望端口上

## 5. 验证方法
- 访问终端输出的 `Local:` 地址，确认页面为最新内容

## 6. 注意事项
- 多开项目或多次启动前端时，建议先确认端口占用情况，避免同时运行多个 dev server。
